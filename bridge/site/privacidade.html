Política de privacidade

Última atualização: 13 de outubro de 2026.

O Organize é um aplicativo pessoal, usado apenas pelo seu autor. Ele não é oferecido ao público.

Dados do Google

  • Gmail (escopo gmail.modify): o app lê somente cabeçalhos das mensagens recentes (remetente, assunto, data, marcação de não lida) para mostrar um resumo na tela inicial, e remove a marcação de não lida quando o usuário pede "Marcar como lida". O corpo e os anexos nunca são lidos nem guardados, e nenhuma mensagem é enviada, apagada ou movida.
  • Google Drive (escopo drive): o app lista, cria, move, renomeia, envia, compartilha e envia para a lixeira arquivos e pastas somente quando o próprio usuário pede essas ações no app.

Armazenamento e segurança

Os tokens de acesso ficam cifrados (AES-256-GCM) no servidor do app e nunca são enviados ao aplicativo instalado. Os cabeçalhos de e-mail sincronizados ficam no banco de dados do app, acessível apenas pela conta do usuário. Nenhum dado é vendido, compartilhado com terceiros ou usado para publicidade ou treinamento de modelos.

O uso de dados recebidos das APIs do Google segue a Google API Services User Data Policy, incluindo os requisitos de uso limitado.

Remoção

A qualquer momento o usuário pode desconectar o Gmail ou o Drive em Ajustes: o acesso é revogado e os dados correspondentes são apagados do servidor. Também é possível revogar em myaccount.google.com/permissions.
