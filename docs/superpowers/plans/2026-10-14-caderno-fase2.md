## API fixa (A e B implementam; C usa)

`app/lib/notebook/intelligence/` (Dart puro, exceto `mlkit_recognizer.dart`):
- `class InkLine { List<String> strokeIds; Rect bounds; double baselineY; double angle; List<InkWord> words; }`, `class InkWord { List<String> strokeIds; Rect bounds; String? text; List<String> candidates; }`.
- `List<InkLine> segmentLines(PageDoc doc, {Set<String>? only})` — agrupa traços (ignora marca-texto) em linhas (sobreposição vertical/baseline) e palavras (lacuna horizontal > ~0,6× altura-x da linha). Determinístico e estável.
- `PageDoc straighten(PageDoc doc, Set<String> ids, String Function() newId)` — por linha: regressão da baseline → gira em torno do início da linha para ficar horizontal; normaliza a altura-x das palavras para a mediana da linha (escala ≤ ±25 %); iguala o espaçamento entre palavras à mediana; não mexe em textos/imagens; devolve o doc com os traços substituídos (ids novos, tombstones dos antigos).
- Gestos: `sealed class InkGesture` com `ScratchOut(Set<String> targetIds)`, `InsertSpace(Offset at, double width)` (∧ / "acento circunflexo" entre palavras), `SplitWord(String strokeOrWordIds, double x)` (traço vertical curto atravessando uma palavra), `JoinWords(Set<String> ids)` (arco "∪" sob o vão entre duas palavras); `InkGesture? detectGesture(Stroke s, PageDoc doc, List<InkLine> lines)` — só reconhece com confiança alta (rabisco: ≥ 4 inversões de direção horizontais cobrindo ≥ 60 % da largura de uma palavra; ∧: dois segmentos quase retos com ângulo 30–120° e ponta para cima, entre palavras da mesma linha; vertical: altura ≥ 0,8× altura da linha e largura ≤ 0,15× altura, cruzando uma palavra; arco: curvatura para baixo-cima sob o vão de duas palavras adjacentes); qualquer dúvida → `null` (o traço vira tinta normal). `PageDoc applyGesture(PageDoc, InkGesture, String Function() newId)`.
- Reconhecimento: `abstract class InkRecognizer { Future<bool> isModelReady(); Stream<double> downloadModel(); Future<List<String>> recognize(List<Stroke> strokes, {Size? writingArea, String preContext = ''}); }` (candidatos em ordem; pt-BR); `NoopInkRecognizer` (Linux/web/testes); `MlKitInkRecognizer` (Android, pacote `google_mlkit_digital_ink_recognition`, modelo `pt-BR`, download **só no Wi-Fi** a menos que o usuário confirme, com progresso).
- Ortografia: `abstract class SpellChecker { Future<List<String>?> suggestions(String word); }` (`null` = palavra correta) com `PlatformSpellChecker` (Android: `DefaultSpellCheckService` do Flutter, locale pt-BR) e `NoopSpellChecker`.
- `class PageTranscript { Map<String,String> wordText /*chave = ids do InkWord ordenados e unidos por ','*/; String text; }` e `Future<PageTranscript> transcribe(PageDoc doc, InkRecognizer r)` (linha a linha, `preContext` = linha anterior; texto da página = linhas separadas por `\n`).

## Task A — Geometria (Onda 1)
`segmentLines`, `straighten`, `detectGesture`/`applyGesture` com testes extensivos em `app/test/notebook/intelligence/` usando traços sintéticos realistas (palavras escritas com amostras de caneta: letras como polilinhas, linhas inclinadas 3–10°, tamanhos variando, palma/marca-texto ignorados). Casos negativos dos gestos (escrita normal com "m", "w", "u", "n", "l", "i", "v" **não** pode virar gesto — teste com várias palavras pt-BR). Desempenho: segmentar 2.000 traços < 50 ms (JIT). Não toque em `app/lib/notebook/ui/`, `state/` nem `data/`.

## Task B — Reconhecimento, ortografia e texto da página (Onda 1)
`InkRecognizer` (+ Noop, + MlKit), `SpellChecker` (+ Noop, + Platform), `transcribe`, modelo (download, estado, apagar), e integração no `NotebookController` (`app/lib/notebook/state/`): depois de ~3 s sem traços numa página (e ao sair), transcreve em segundo plano e grava `recognized_text` da página junto do próximo `savePage` (o repositório já tem a coluna; inclua no update e no merge — o texto reconhecido é derivado: em conflito vale o do documento mesclado, re-transcrito). Só no Android; no Linux/Windows o texto vindo do servidor continua sendo usado na busca. Ajustes → "Escrita à mão": estado do modelo pt-BR (baixar ~20 MB, só Wi-Fi por padrão, progresso, apagar) e chaves "Reconhecer escrita (busca)", "Corretor ortográfico", "Gestos de edição" (padrão ligados), guardadas por aparelho. Testes com recognizer/spellchecker falsos (debounce, gravação do texto, conflito, desligado não reconhece, modelo ausente não quebra). Verificar no `pubspec` a versão do plugin compatível com o SDK atual; `flutter build apk --debug` verde (minSdk/Gradle). Não toque em `app/lib/notebook/ui/` (exceto um arquivo novo de Ajustes se preferir colocar lá — melhor em `app/lib/features/settings/handwriting_card.dart`).

## Task C — Interface (Onda 2)

- **Página**: menu da página ganha "Converter página em texto", "Endireitar página", "Copiar texto da página".

- **Gestos**: no fim de cada traço (modo caneta, gestos ligados), `detectGesture` → se gesto, aplica (com animação curta e desfazer) em vez de gravar a tinta.
